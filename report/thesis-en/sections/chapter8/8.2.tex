\section{Search Quality Evaluation}
\label{sec:8.4}

\paragraph{Method.} The system's pipeline was run on the labelled frame sets of the seven WILDTRACK cameras. Each track was labelled with the majority person by matching its boxes with the dataset labels, for evaluation only. The evaluation set has 6 queries, each in three forms: a cropped image, an English description and a set of attributes. The observation used as the query image is removed from the gallery. \emph{Recall@$k$} is the fraction of queries with at least one correct result in the top $k$, with $k \in \{4, 8, 12, 16\}$, and \emph{MRR} is the mean reciprocal rank of the first correct result. Run 1 used a confidence threshold of 0.25 and a gallery of 1,552 tracks, for all three forms. Run 2 used the current threshold of 0.1, a gallery of 1,526 tracks and an extended attribute set, but only re-evaluated attribute search. Search by image and by text at threshold 0.1 has \emph{not been measured}.

\paragraph{Person detection.} In run 1, detection reached a precision of 0.58 and a recall of 0.54; in run 2, after lowering the confidence threshold to 0.1, precision was 0.43 and recall 0.64. The two runs differ in both threshold and attribute labels, so they are only compared qualitatively: lowering the threshold misses fewer people but produces more false detections, most of which are removed by tracking (Section~\ref{sec:3.2.5}).

\paragraph{Discussion.} Search by image performs well: in run 1, every query has a correct result in the top 8. Search by text and by attributes, in contrast, brings no correct result into the top 16; in run 2, the first correct result of the attribute queries only appears at ranks 87, 241 and 365, and the extended attribute set does not improve the results. The main cause is the domain gap between CUHK-PEDES, on which RaSa was trained, and the person images cropped automatically from the full frames of WILDTRACK (Section~\ref{sec:3.5.4}). Search by image is therefore the main form of the system, while search by text and by attributes plays a supporting role and needs careful visual assessment by the user. This weakness of text search is the starting point of the research in Part~II (Chapter~\ref{chapter:r-overview}).

\paragraph{Qualitative check on the demonstration data.} On the demonstration data (Section~\ref{sec:7.2}), five query images were tried with the top 8 results and assessed visually: three queries had 8/8 correct results, one 7/8 and one 4/8; the correct results lay on 4 to 5 different cameras. This is only a qualitative check on a dataset different from the evaluation set and cannot be compared with the Recall values of Table~\ref{tab:recall}.
